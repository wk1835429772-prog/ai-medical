# 临床查房

ICU 查房助手，自动获取患者临床数据，按七维框架生成结构化汇报。

## 触发条件

| 输入 | 动作 |
|------|------|
| `患者列表` | 列出所有管床患者 |
| `查{数字}床` | 查询指定床号患者的完整查房汇报 |
| `全查` | 生成所有患者的查房汇报 |
| `异常值` | 汇总所有患者异常/危急指标 |

## 工作流

1. 匹配用户输入，确定调用哪个 MCP 工具
2. 调用对应的 MCP 工具获取数据
3. AI 根据返回数据，按七维框架格式化输出
4. 异常值用 🔴（偏高）和 🔵（偏低）标注
5. 危急值用 🚨 标注

## 七维框架

分析每个患者时，按以下顺序评估：
1. **原发病** — 引流量、引流性状、伤口评估
2. **循环** — BP/HR/SpO₂、出入量平衡、MAP
3. **呼吸** — 血气分析、呼吸机参数、氧合指数OI
4. **感染** — 体温、WBC、PCT、IL-6
5. **脏器** — 尿量、肾功能、凝血、电解质
6. **营养** — 营养途径、入量、白蛋白
7. **VTE** — 预防措施、D-二聚体

## 注意

- 汇报要简洁，适合手机屏幕阅读
- 正常值无需重复，重点突出异常
- 术后天数从手术日期自动计算
- 数据来源为患者最新日卡数据
